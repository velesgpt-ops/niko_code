# Snake Game

Классическая игра Змейка — единственный HTML-файл, никаких зависимостей.

## Запуск

Откройте `index.html` в браузере.

## Управление

| Действие | Клавиши |
|---|---|
| Движение | `WASD` или стрелки |
| Пауза | `P` или `Space` |
| Старт / рестарт | `Enter` или кнопка на экране |
| Мобильные | Свайп или D-pad кнопки |

## Особенности

- Тёмная тема, Canvas-рендеринг
- 5 уровней скорости (ускорение на 5 / 10 / 20 / 35 очков)
- Плавная анимация еды (glow-пульсация)
- Градиентная змея с глазами
- Сохранение рекорда (localStorage)
- Адаптивный размер под экран
